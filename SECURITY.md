# Security Policy

## Intentional Vulnerabilities

This repository intentionally contains vulnerable code and configurations for educational purposes.

Do not report intentionally vulnerable lab scenarios as repository security vulnerabilities.

## Reporting a Vulnerability

Please use GitHub Private Vulnerability Reporting to report vulnerabilities affecting:

- repository infrastructure;
- repository automation;
- credentials or secrets;
- unintended security flaws;
- other security issues not intentionally included as part of a lab scenario.
